# 第四阶段：Agent / Workflow / LangGraph

---

## 阶段目标

掌握 AI Agent 和复杂工作流开发，理解如何让 AI 自主决策、调用工具、并完成多步骤复杂任务。

### 你将学会什么

```
1. 理解 Agent 和普通 LLM 调用的本质区别
2. 掌握 ReAct / Planner-Executor 等核心 Agent 模式
3. 理解 Workflow（工作流）的概念和编排方式
4. 学会使用 LangGraph 构建 Agent 应用
5. 开发 Multi-Agent 协作系统
6. 开发可视化 Workflow Builder
```

---

## 为什么这一阶段如此重要

前三个阶段你学的是：
- Stage 1：LLM 基础 → 让 AI 能对话
- Stage 2：Tool Calling → 让 AI 能用工具
- Stage 3：RAG → 让 AI 能查资料

但这些都是**单轮、单步**的能力。

真实的 AI 产品需要：
- AI **自己决定**下一步做什么（Agent）
- AI **拆解任务**然后逐步执行（Planner）
- AI **在多个步骤间流转**（Workflow）
- **多个 AI 协作**完成复杂目标（Multi-Agent）

这就是 Stage 4 的核心。

## 核心概念预览

### Agent 是什么

普通 LLM 调用：
```
用户提问 → LLM 回答 → 结束
```

Agent：
```
用户提问 → LLM 思考 → 决定是否需要工具
  → 调用工具 → 获取结果 → 继续思考
  → 决定是否需要更多信息
  → 调用更多工具 → ...
  → 最终回答 → 结束
```

核心区别：**Agent 有循环（Loop）**。

### Workflow 是什么

Workflow 是预定义的任务流程：
```
[输入] → [节点A] → [节点B] → [判断] → [节点C/节点D] → [输出]
```

Agent 是 AI 自主决策，Workflow 是人预设路径。两者经常结合使用。

### LangGraph 是什么

LangGraph 是 LangChain 团队开发的 Agent/Workflow 框架，核心思想：
- 用**图（Graph）**来描述 Agent 的行为
- 节点 = 处理步骤
- 边 = 流转逻辑
- 状态 = 在节点间传递的数据
